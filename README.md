# Campus Notification System

## Overview
Full Stack assessment for Affordmed Campus Hiring Evaluation.

## Structure

- `notification_system_design.md` — Stages 1–6
- `notification_app_be/` — Node.js + Express backend
- `notification_app_fe/` — React + Material UI frontend
- `logging_middleware/` — Custom logging middleware
